# conduitio

This name is reserved for the ConduitIO Python SDK: connectors, processors and the embedded client.
This release contains no code.

Until the unified package is published, use
[`conduit-connector-sdk`](https://pypi.org/project/conduit-connector-sdk/) and
[`conduit-client`](https://pypi.org/project/conduit-client/).
See [Conduit](https://github.com/ConduitIO/conduit).
